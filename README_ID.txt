UNTUK PS2 ASLI VIA OPL (file CHD - hemat unduhan, spasi huruf standar)
File CHD sudah jadi (tak perlu mem-patch), memakai spasi huruf standar bawaan game:
- "Sengoku Basara 2 Heroes (ID v0.99.1) OPL.chd" .............. Full Indo
- "Sengoku Basara 2 Heroes (ID v0.99.1 Koban x10 SAFE) OPL.chd"  Full Indo + koban x10
  SHA-1 Full Indo CHD  : 725A581444C3DA3DE75F28C7F2ED374FDD9F4075
  SHA-1 Koban x10 CHD  : 7B60165AD999F051AAB7145C7466AE4B3D86C230
Cara pakai: OPL TIDAK membaca CHD. Di PC, ekstrak dulu ke ISO dengan chdman (ada di
paket MAME):
  chdman extractdvd -i "Sengoku Basara 2 Heroes (ID v0.99.1) OPL.chd" -o "SB2H.iso"
Lalu salin ISO (4,68 GB) ke OPL: HDD internal/SMB, atau USB berformat exFAT (OPL 1.2.0
ke atas). USB FAT32 tidak muat file di atas 4 GB: pecah dulu ISO ke format UL dengan
USBUtil. Unduhan CHD ~3,4 GB (lebih kecil dari ISO 4,68 GB).
Emulator (PCSX2, AetherSX2/NetherSX2, ARMSX2) bisa membuka CHD langsung.

CARA MEMASANG (format .xdelta)
[A] patcher.html - satu patcher untuk Windows, macOS, Linux dan Android (disarankan)
  1. Buka patcher.html di browser: Chrome atau Edge (paling baik), Firefox, Safari.
  2. Pilih ISO sumber (lihat PILIH PATCH), lalu pilih file .xdelta.
  3. Klik "Patch sekarang" dan pilih lokasi simpan ISO baru (butuh ruang ±4,7 GB).
  Di Chrome/Edge ISO baru ditulis langsung; di Firefox/Safari/Android hasilnya
  diunduh streaming. Semua proses terjadi di perangkatmu, tidak ada file yang
  diunggah, ISO sumber tidak diubah. Android: biarkan layar menyala sampai selesai.
[B] xdelta (xdelta UI, DeltaPatcher, atau baris perintah)
  xdelta3 -d -s "ISO sumber.iso" basara2_id_v0.99.1.xdelta "ISO hasil.iso"

MEMAINKAN (semua emulator & PS2 asli)
Semua terjemahan ada di dalam ISO; tidak perlu paket tekstur atau cheat apa pun.
File game, ID game, ukuran ISO dan susunan file sama persis dengan aslinya, jadi
setelan per-game emulator tetap berlaku (varian koban x10: lihat catatan CRC di atas).
- PC: PCSX2 (versi 1.6 ke atas) - buka ISO hasil patch seperti biasa.
- Android: ARMSX2, AetherSX2 / NetherSX2 - salin ISO hasil patch ke HP lalu buka.
  Mem-patch langsung di HP bisa lewat patcher.html di Chrome Android (butuh ruang
  ±4,7 GB), tapi lebih cepat di PC lalu salin hasilnya.
  Di emulator, ISO boleh dikompres ke .CHD (chdman) untuk menghemat ruang.
- PS2 asli: lewat OPL (HDD/SMB, USB exFAT, atau USB FAT32 dengan format UL) memakai
  ISO, bukan CHD (lihat bagian OPL di atas).
- Memory card: save Sengoku Basara 2 Heroes versi Jepang tetap bisa dipakai.
- Video pembuka bab di-encode ulang dengan format yang sama dengan aslinya
  (MPEG-1 512x448, susunan data per GOP sama), jadi diputar oleh dekoder game
  sendiri di semua emulator.
- PCSX2: kalau jendela game berubah lebar sendiri (misalnya saat memilih jurus,
  karena pratinjau jurus adalah video), buka Settings > Graphics > Display dan
  set "FMV Aspect Ratio Override" ke Off. Ini setelan emulator, bukan bug patch.

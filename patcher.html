Bantuan
  • ISO yang dibutuhkan: Sengoku Basara 2 - Heroes (Japan) (SLPM-66848), 4.677.795.840 byte, satu file .iso. Kalau ISO-mu .chd/.cso/.7z, ubah atau ekstrak dulu ke .iso.
  • Patch penuh (terjemahan lengkap / koban) bisa dipasang ke ISO Jepang asli maupun ISO Indonesia versi lama mana pun (v0.97, v0.98, v0.99, termasuk hasil CHD/OPL), dan hasilnya selalu sama persis. Jadi patch penuh juga bisa dipakai untuk memperbaiki ISO yang bermasalah. Patch deskripsi item tetap butuh ISO Jepang asli.
  • Butuh ruang kosong ±4,7 GB untuk ISO baru. ISO asli tidak diubah.
  • Di Chrome/Edge desktop kamu memilih lokasi simpan dulu, lalu ISO baru ditulis langsung (cepat, tanpa pemeriksaan). Di HP/Android dan browser lain, ISO baru langsung diunduh secara streaming (hemat memori, tidak macet di 1%); tunggu sampai unduhan selesai.
  • Android: biarkan layar menyala dan jangan pindah aplikasi sampai selesai. Hasilnya bisa langsung dibuka di ARMSX2, AetherSX2 atau NetherSX2.
  • Disarankan pakai file .xdelta (lebih cepat — memakai mesin xdelta3 asli). File .patch lama tetap didukung.
  • Semua proses terjadi di perangkatmu. Tidak ada file yang diunggah ke mana pun.
